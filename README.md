# GeoFS SAAF ORBATS
Tampermonkey addon that makes ORBATS (order of battle) bases for the GMRP-recognized SAAF red on the GeoFS Nav Panel.
This addon is frequently updated if territory changes are made.
Original addon created by Squirtle747 for USAF, adapted for SAAF by amateurtheairbus.

How to install:
  1. Download the Tampermonkey Chrome extension from the Chrome Web Store. Also works on chromium-based browsers like Helium.
  2. From any tab, click on the puzzle-piece icon by the sarch bar > Tampermonkey > Create a New Script.
  3. Copy userscript.js into the text editor, then use File > Save or Ctrl+S/⌘+S to save.
  4. Reload geo-fs.com, if you have it open. South African Military bases should be highlighted in the nav panel.
